## Problem Statement

Schools want an early warning system for students at risk of dropping out, so
teachers and administrators can intervene before it happens. This project
builds a machine learning model that predicts a student's dropout risk level
(**Low / Medium / High**) from attendance, academic performance, and
socio-economic factors relevant to the Nigerian secondary school context.

## Dataset

A **synthetic dataset** of 1,000 Nigerian secondary school students, engineered
to reflect real, documented dropout drivers in Nigeria rather than
random/generic data:

| Factor | Why it matters |
|---|---|
| Attendance rate | Direct predictor of disengagement |
| Term 1–3 average scores | Academic performance trend |
| Household income band | Financial pressure is a major dropout driver |
| Distance to school (km) | Long commutes increase absence/dropout risk |
| Part-time work / trading | Common reason students miss school in Nigeria |
| Parent education level | Correlates with support at home |
| Family support | Emotional/practical backing affects persistence |
| Health issues | Disrupts attendance and performance |

Other columns: state, school type (public/private), gender, age, class level
(JSS1–SS3), number of siblings, scholarship status, extracurricular involvement.

**Label generation:** each student's `dropout_risk_level` was derived from a
weighted formula combining attendance, grades, income, distance, part-time
work, family support, and health issues, plus random noise — not copied from
a real institution's records. This is disclosed for transparency; see
Limitations below.

File: `nigerian_student_dropout_dataset.csv`

## Approach

1. **EDA** - checked class balance and how attendance/scores vary by risk level.
2. **Preprocessing** — one-hot encoding for categorical features, standard
   scaling for numeric features, via a single `ColumnTransformer`.
3. **Feature leakage guard** - `risk_score_raw` (the raw score used to *generate*
   the label) and `student_id` were dropped from training features.
4. **Models trained:**
   - Logistic Regression (interpretable baseline)
   - Random Forest (main model - better accuracy, gives feature importances)
5. **Evaluation** - accuracy, per-class precision/recall/F1, confusion matrix.
6. **Explainability** - global feature importances from the Random Forest,
   plus rule-based "contributing factor" flags per prediction (e.g., "Low
   attendance rate", "Engages in part-time work").

## Results

| Model | Accuracy |
|---|---|
| Logistic Regression | ~80% |
| **Random Forest (main model)** | **~84%** |

Per-class performance (Random Forest) is strongest for Low risk (highest
recall) and reasonable for Medium/High, with most misclassifications landing
in the adjacent risk band (e.g., Medium predicted as Low) rather than jumping
from Low straight to High - see the confusion matrix in the notebook.

**Top contributing factors** (by feature importance): attendance rate,
overall average score, household income band, and part-time work status.

## How to Run

### 1. Train the model (notebook)
1. Open `student_dropout_predictor.ipynb` in Jupyter, VS Code, or Google Colab.
2. Upload/place `nigerian_student_dropout_dataset.csv` in the same folder/session.
3. Run all cells top to bottom. This trains both models, prints evaluation
   metrics, shows the feature importance chart, and saves
   `student_dropout_model.pkl`.

### 2. Run the demo app (Streamlit)
1. Make sure `app.py` and `student_dropout_model.pkl` are in the same folder.
2. Install dependencies:
   ```bash
   pip install streamlit joblib pandas scikit-learn
   ```
3. Run:
   ```bash
   streamlit run app.py
   ```
4. Fill in a student's details and click **Predict Risk** to see the risk
   level, probability breakdown, and contributing factors.

   *(If running in Google Colab, Streamlit needs a tunnel — see project notes
   for the `localtunnel` workaround used during development.)*

## Limitations

- **Synthetic data:** the dataset was generated to reflect known Nigerian
  dropout patterns, not collected from real schools. Relationships between
  features and risk are realistic but simplified, and a production system
  should be retrained on real school records (e.g., state UBEC/SUBEB data).
- **Label is rule-derived, not ground truth:** since real dropout outcomes
  weren't available, risk level was computed from a weighted formula rather
  than observed student outcomes.
- **No temporal/longitudinal data:** the model uses a snapshot (one school
  year) rather than tracking a student's trend over multiple years.
- **Fairness consideration:** features like household income and school type
  correlate with structural inequality; risk scores should support
  interventions (extra support, scholarships) rather than any punitive use.
